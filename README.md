# Quadratisches Lerncamp

Lernseite für quadratische Funktionen (Klasse 10): 8 Lerntage mit je 6 Aufgaben,
Tipps, Punkten und einem Lösungswort am Ende jedes Tages.

- `index.html` – die Lernseite
- `pruefen.html` – Lösungswörter prüfen (für den Nachhilfelehrer)
- `aufgaben.js` – alle Aufgaben, Tipps und Lösungen
- `code.js` – Ver- und Entschlüsseln der Lösungswörter
- `app.js`, `style.css` – Logik und Aussehen

Reines HTML/JavaScript, kein Server nötig. Der Fortschritt wird im Browser gespeichert.
